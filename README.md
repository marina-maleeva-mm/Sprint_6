# Sprint_6 — Автотесты для сервиса Яндекс Самокат

# Описание проекта
В проекте реализованы автотесты для сайта:
https://qa-scooter.praktikum-services.ru/

Тестирование выполнено с использованием:
- Python
- Pytest
- Selenium
- Allure

# Структура проекта

- 'pages/' — Page Object модели страниц
- 'locators/' — локаторы элементов
- 'tests/' — тесты
- 'conftest.py' — фикстуры
- 'data.py' — тестовые данные
- 'requirements.txt' — зависимости проекта


# Покрытые сценарии

# 1. FAQ 
- Проверка раскрытия ответов
- Проверка соответствия текста ответа

# 2. Заказ самоката
- Проверка полного позитивного сценария
- Две точки входа:
  - кнопка "Заказать" в шапке
  - кнопка "Заказать" внизу страницы
- Используется параметризация с разными данными

# 3. Редиректы
- Проверка перехода по логотипу Самоката
- Проверка перехода на Дзен по логотипу Яндекса
